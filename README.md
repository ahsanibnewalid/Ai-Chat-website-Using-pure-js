# AI Chat Website — Pure JavaScript

A lightweight chatbot interface built with plain HTML, CSS, and JavaScript.

## Features

- 💬 Chat-style interface
- 🤖 Predefined chatbot responses
- 📱 Mobile and desktop friendly
- 🧩 No frontend framework required

## Run locally

```bash
git clone https://github.com/ahsanibnewalid/Ai-Chat-website-Using-pure-js.git
cd Ai-Chat-website-Using-pure-js
python -m http.server 8000
```

Open `http://localhost:8000` in your browser.

## Tech stack

HTML5 · CSS3 · JavaScript
